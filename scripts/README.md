# Standalone R scripts

Standalone scripts are separated from the figure-specific source-data folders to keep code and data organization explicit.

## Figure 1 scripts

- `Fig1B-1.R`
- `Fig1B-2.R`
- `Fig1C-1.R`
- `Fig1C-2.R`
- `Fig1C-3.R`
- `Fig1D-1.R`
- `Fig1D-2.R`
- `Fig1E-1.R`
- `Fig1E-2.R`
- `Fig1F.R`

Run Figure 1 scripts with `fig1/` as the working directory. Example:

```bash
cd fig1
Rscript ../scripts/fig1/Fig1F.R
```

## Figure 2 scripts

- `Fig2F.R`
- `Fig2G.R`
- `Fig2H.R`
- `Fig2I.R`
- `Fig2J.R`
- `Fig2K.R`
- `Fig2L.R`
- `Fig2M.R`

Run Figure 2 scripts with `fig2/` as the working directory. Example:

```bash
cd fig2
Rscript ../scripts/fig2/Fig2G.R
```

### Figure 2 execution note

`Fig2G.R` should be run before `Fig2F.R`, because Figure 2F reads the 3-group metabolomics statistics table generated by Figure 2G.

The figure-level R Markdown files (`fig1/fig1.Rmd` and `fig2/fig2.Rmd`) remain self-contained and can be knitted directly from their corresponding figure directories.
