# enterococcus-phage-levodopa-analysis

Analysis code for the Enterococcus-phage-levodopa responsiveness study.

This repository contains R scripts used for microbiome, virome, metabolomics, bacterial strain, phage-host association, clinical correlation, and prediction-model analyses.

## Repository structure

- `code/human/`  
  Scripts for the human Parkinson's disease cohort, including 16S rRNA microbiome analysis, virome analysis, differential abundance analysis, clinical association analysis, Enterococcus-phage correlation, and prediction-model analysis.

- `code/animal/16S/`  
  Scripts for animal 16S rRNA microbiome analyses.

- `code/animal/MET/`  
  Scripts for animal striatal metabolomics analyses.

- `code/strains/`  
  Scripts for bacterial strain analysis, tyrDC operon analysis, prophage analysis, and regulatory-region analysis.

## Data availability

Raw sequencing data are deposited or will be deposited in NCBI SRA under the corresponding BioProject/SRA accession numbers.

The targeted LC-MS/MS metabolomics data have been deposited in the MetaboLights repository 

## Requirements

The analyses were performed mainly in R.

Required R packages vary by script and may include:

- `tidyverse`
- `data.table`
- `vegan`
- `ape`
- `phyloseq`
- `ggplot2`
- `pROC`
- `logistf`
- `ComplexHeatmap`
- `circlize`
- `igraph`
- `ggraph`
- `patchwork`
- `broom`

Users should check and install the required packages before running individual scripts.

## Usage

Scripts are organized by analysis module.

Users should modify local input and output paths before running the scripts. Some scripts depend on intermediate files generated by upstream analyses.

The scripts are intended to document the analysis workflow used in the associated manuscript and may require the corresponding metadata, abundance matrices, taxonomy tables, clinical variables, and deposited raw data.
