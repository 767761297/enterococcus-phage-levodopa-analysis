# enterococcus-phage-levodopa-analysis

Analysis code for the Enterococcus-phage-levodopa responsiveness study.

This repository contains R scripts used for microbiome, virome, metabolomics, bacterial strain, phage-host association, clinical correlation, and prediction-model analyses.

## Repository structure

```text
code/
├── human/
│   └── Analysis scripts for the human Parkinson's disease cohort, including 16S rRNA microbiome analysis, virome analysis, differential abundance analysis, clinical association analysis, Enterococcus-phage correlation, and prediction-model analysis.
├── animal/
│   ├── 16S/
│   │   └── Animal 16S rRNA microbiome analysis scripts.
│   └── MET/
│       └── Animal striatal metabolomics analysis scripts.
└── strains/
    └── Bacterial strain, tyrDC operon, prophage, and regulatory-region analysis scripts.
